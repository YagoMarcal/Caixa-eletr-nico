#  Caixa Eletrônico

Programa em **C** que simula um saque de dinheiro e retorna as notas que seriam utilizadas na operação.

##  Objetivo

Simular o funcionamento básico de um caixa eletrônico: o usuário informa o valor que deseja sacar e o programa calcula e exibe a quantidade de cada nota necessária para compor esse valor, utilizando o menor número possível de notas.

##  Funcionalidades

- Solicita ao usuário o valor do saque
- Calcula a combinação de notas para o valor informado
- Exibe a quantidade de cada tipo de nota que seria entregue
- Resolve o problema com lógica de divisão inteira e resto (módulo)

## 🛠️ Tecnologias

- Linguagem **C**
- Compilador GCC (ou qualquer compilador C compatível)

##  Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/YagoMarcal/Caixa-eletr-nico.git
   cd Caixa-eletr-nico
   ```
2. Compile o código (ajuste o nome do arquivo `.c` se for diferente):
   ```bash
   gcc main.c -o caixa
   ```
3. Execute:
   bash
   ./caixa
   
   No Windows: caixa.exe

##  Exemplo de uso

```
Digite o valor do saque: 380

Notas utilizadas:
1 nota(s) de R$ 200
1 nota(s) de R$ 100
1 nota(s) de R$ 50
1 nota(s) de R$ 20
1 nota(s) de R$ 10
```

> O formato da saída e as notas disponíveis podem variar conforme a sua implementação.
